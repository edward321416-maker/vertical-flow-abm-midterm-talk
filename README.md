## 연구 개요

- 이론 틀: 힐리어의 자연 이동(구조가 일차 흐름을 만들고 유인이 증폭한다), 선택 모형은 Huff 중력모형과 McFadden 다항 로짓.
- 모형: GAMA 2025.06.4. 지상 9개 층(S00~S08 = 1~9층), 4일 영업 주기. 분석 단위는 **층간 경계**(b층→b+1층, 경계 1~8). 층 평면과 층 내부 보행은 모형에 없습니다(층 단위 거시 모형).
- 실험 1(E1): 앵커 집객 강도 γ ∈ {0, 2, 4, 8} × 동선(연속형 `cont` / 분절형 `frag`), 조건당 200회 = 1,600회. 층별 앵커 비중은 0~0.5 균등 난수.
- 실험 2(E2): 앵커 총량을 같게(합 1.60) 두고 배치 4종(최상층 집중 `top1`, 저층 집중 `low3`, 균등 `uniform`, 징검다리 `step3`)을 γ=4에서 비교, 조건당 100회. γ=0 대조군 포함.

### 핵심 결과 (원자료 CSV로 검증)

| RQ | 결과 |
|---|---|
| RQ1 (γ=0 기준선) | 연속형 1→2층 12,346명 → 8→9층 448명(1층의 3.6%), 분절형 9,802 → 408명(4.2%). 분절형은 첫 경계 유량이 20.6% 적음. 로그 선형 감소 가설 기각(이탈 폭 0.131 / 0.152, F 검정 p<0.001) |
| RQ2 (무엇이 위로 올리나) | 경계 유량 변동 설명 비중(경계·반복 고정효과 제거, quasi-Poisson deviance): 인접층 격차 4~22%, 위층 평균 29~57%, **바로 위층 앵커 46~71%** |
| RQ3 (동선 마찰) | 앵커 기울기 잠식률 γ=2 6.7%(CI 2.7~10.5), γ=4 0.8%(−4.1~5.2), γ=8 1.7%(−6.4~8.6). 기저 수준은 마찰로 크게 하락(−20.6%) |
| RQ4 (배치 4종, 최상층 도달 T) | 최상층 집중 0.587(9,112명) > 징검다리 0.140(2,197명) > 균등 0.059(975명) > 저층 집중 0.015(286명). Holm 보정 쌍대 비교 p<0.001 |

한계(논문 자체 기술): 유인이 지수형이고 포만·혼잡 미반영, 구조 변수는 2수준만 조작, 가상 건물, 층 내부 보행 없음.

## 데이터 사전: `analysis/outputs/aik/aik_boundary_rep.csv`

한 행 = (셀, 반복, 경계). 20,800행.

| 열 | 뜻 |
|---|---|
| `cell_id`, `exp`, `pattern`, `gamma`, `circ` | 실험 셀. 예: `aik_e1_g0_cont`, `aik_e2_top1_g4_cont` |
| `rep_id` | 반복 번호(E1 1~200, E2 1~100) |
| `boundary_order` | 경계 1~8 (`b`층→`b+1`층). `boundary_id` = `S00-S01` 등 |
| `U` | 그 경계를 위로 통과한 인원(4일 합) |
| `U_esc`, `U_stairs`, `U_elev` | 수단별 인원(에스컬레이터, 계단, 엘리베이터). 합 = `U` |
| `x_lower`, `x_upper` | 경계 아래층/위층의 앵커(식음) 비중 |
| `M_above` | 경계 위 모든 층의 평균 앵커 비중 |
| `delta` | 인접층 격차 = `x_upper − x_lower` |
| `U_prev`, `U_first` | 직전 경계 인원, 1번 경계 인원 |
| `AUFR`, `RUI` | 직전 경계 대비 비율, 1번 경계 대비 비율 |

다른 CSV: `aik_a1_profile`(γ=0 경계별 평균과 분위수), `aik_a1_shape`(로그 선형 검정), `aik_a2_theta`(승수), `aik_a2b_constructs`(설명 비중), `aik_a3_moderation`(잠식률), `aik_a4_reach`/`aik_a4_contrasts`(도달 지수와 Holm 비교), `aik_e2_profile`(배치별 경계 프로필).

**층 번호 규칙**: 경계 b는 `b`층→`b+1`층(S00 = 1층). 경계 b는 도착층(`b+1`)의 줄에 놓습니다.

## 발표 설계 (현행 기준: `presentation/plans/slide_content_master.md`)

- **현재 중심 주장**: "수직동선은 기본적인 상행 흐름을 제약하고, 프로그램의 유인력과 배치는 그 흐름이 상층부까지 이어지는 양상을 변화시킨다." 가상 모형의 **조건부 해석**이다.
- 9장, 합계 300초. 현재 시간표: **10 / 30 / 30 / 40 / 40 / 50 / 40 / 40 / 20초**. 표지·서론·이론의 콘텐츠 기획을 완료(잠정)했고, **다음 진행은 4페이지 연구 방법**이다. 이전 메시지 설계문과 HTML은 이력으로 보존한다.

## 시각화 방향 (`presentation/`)

- 원칙: 한 장에 한 질문, 면적 대부분이 데이터, 3초 안에 읽히기, 세로축 = 건물의 층, 색 의미 고정(연속형 남색, 분절형 갈색, 수단 3색), 실제 CSV 값만 사용.
- 채택: 5번 나비차트(`presentation/slides/slide_05_butterfly.png`), 6번 같은 세로축 산점도 2개, 8번 배치 4종 연결 시트.
- 폐기: 사람이 돌아다니는 3D 렌더와 시뮬레이션 장면(모형에 층 평면이 없어 연출이 되고 데이터를 가림).
- 참고 이미지 문법(Oxford Circus 'Street Choreographies')을 차용한 "수직 동선의 안무" 시트: `presentation/plans/plan_05_choreography_sheet.html`.
- 제작 방식: 슬라이드를 HTML/SVG(1920×1080)로 설계하고 Chromium으로 고해상도 렌더링(`presentation/tools/modal_render.py`, Modal 사용), 글꼴 Pretendard.

## 주의점 (꼭 읽어 주세요)

1. **원고의 오류 1건**: 원고 본문의 "8번 경계 연속형 446명"은 원자료로는 **447.8명(448)** 입니다(원고 그림 1은 448). 발표 자료는 448을 씁니다.
2. **논문에 없는 새 집계**: 앵커 위치에 따라 주력 수단이 에스컬레이터에서 엘리베이터로 바뀌는 현상(예: γ=0 연속형은 5→6층부터 엘리베이터 우세, 최상층 집중 배치는 4→5층부터 7→8층에서 엘리베이터 71~76%)은 이번에 처음 집계한 값이며 **논문 본문에 없습니다.** 모형의 수단 선택 규칙의 산물일 수 있어 주장으로 쓰기 전에 확인이 필요합니다.
3. **설명 비중의 정의**: RQ2의 "설명 비중"은 AUFR이 아니라 **경계 유량 U**를 종속변수로, 경계와 반복의 고정효과를 뺀 뒤 계산한 값입니다(`analysis/R/experiments/aik_analysis.R`의 A2b). AUFR 산점도로 그리면 결론이 반대로 보입니다.
4. **구버전 초안은 제외**: 작업 폴더에는 직접 입력된 상수가 섞인 옛 초안이 있었고, 이 저장소에는 넣지 않았습니다. 이 저장소의 숫자는 모두 `analysis/outputs/aik/`의 CSV에서 나옵니다.
5. **파일 이름**: 일부 명세에 `alk_boundary_rep.csv`라고 적힌 곳이 있으나 실제 파일은 `aik_boundary_rep.csv`입니다.
6. **외부 연동은 미실행**: `src/services/gstack_sync.js`(Google Sheets/Drive)는 인증 정보가 없어 실제 계정에서 실행한 적이 없습니다.
7. **경로**: 스크립트에는 작성자 PC의 Windows 절대 경로(`D:\vcpf\...`, `D:\Users\...`)가 상수로 남아 있습니다. 실행하려면 경로를 바꾸세요(`build_poster_dataset.py`는 환경변수 `AIK_BOUNDARY_REP_CSV`로 CSV 경로를 받습니다).
8. 시뮬레이션 원자료(반복별 이벤트 로그 등)는 용량 때문에 올리지 않았습니다. 올린 CSV는 집계 결과입니다.
