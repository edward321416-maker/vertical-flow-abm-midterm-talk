# `claude --cloud` 실행 전용 패키지 — 논문 중간발표 PDF 리디자인

> 이 문서는 **Claude Code Cloud Session에서 터미널 `claude --cloud` 명령으로 실행하기 위한 제작 지시서**다. 단순 Claude 채팅이나 로컬 `claude` 세션에 적용하는 명세가 아니다.

## 원격 입력 파일 확인 — 최우선 전제조건

클라우드 환경의 GitHub 체크아웃에서 다음 파일 경로가 **실제로 존재하고 읽히는지** 먼저 확인하라.

- `cloud_task/inputs/vertical_flow_presentation_clear_titles.pdf` — 현재 18장 중간발표 PDF, **수정 대상**
- `cloud_task/inputs/paper_revised_8pages_v2(2).pdf` — 수정 논문 8쪽, 학술적 정합성 기준
- `cloud_task/CLAUDE_CLOUD_TASK.md` — 본 작업 명세
- `analysis/outputs/aik/` 및 관련 저장소의 실행/분석 코드 — 실험 결과 확인용

현재 브랜치의 GitHub 체크아웃만 신뢰한다. 사용자의 PC에 있던 파일, ChatGPT `/mnt/data`, 미푸시 Git 변경사항이 원격에 자동으로 동기화되었다고 가정하지 않는다. 필수 PDF를 읽을 수 없다면 **원본 없이 18장 PDF를 재설계하지 말고** 누락 파일 경로를 정확히 보고하라. PDF를 기존 저장소/브랜치에 노출하는 행위가 개인 정보나 공개 범위를 바꿀 수 있으므로, 직접 외부에 업로드하거나 공개 상태를 변경하지 않는다.

## 실행 모드·자원

- 이번 작업은 중간발표 PDF의 시각자료 개선 **실제 제작 실행**이며, 계획 보고서만 제출해서는 안 된다.
- Claude 클라우드 세션 내에서 사용 가능한 최고 모델 및 최고 지원 effort를 확인하고, 가능한 경우 `best`와 `max`를 선택한다. 지원하지 않는 모델명이나 옵션을 추측해 강제하지 않는다.
- 사용자의 클라우드 세션 크레딧 적용 여부는 Claude가 제공하는 상태를 기준으로 확인한다. 잔액이나 모델 접근을 확인하지 못한 경우 추측하지 않는다.
- Modal은 클라우드 런타임 안에 이미 인증된 사용 가능한 연동이 있을 때만 활용한다. 로컬 자격 증명을 복사하거나 유료 이용을 추가로 개시하지 않는다.
- 기존 GitHub의 원고/실험 결과와 입력 PDF는 읽기 전용으로 취급한다. 작업 산출물은 `cloud_task/output/`에 별도 생성한다.
- PDF를 완성한 뒤 실제로 모든 18장 또는 수정된 장수를 렌더링·검토한다. 문제가 있는 상태로 완료를 선언하지 않는다.
- 완료 후 `cloud_task/output/vertical_flow_midterm_refined.pdf`를 포함한 변경사항을 **별도 작업 브랜치**에 남기고, 가능하고 허용된 경우 검토 가능한 Draft PR을 준비한다. 기본 브랜치에 병합하거나 원고를 덮어쓰지 않는다.
- GitHub 원격에 파일을 전달하지 못하는 경우 유효한 다운로드/반환 방법을 확인하고, 지원되지 않으면 불가능하다고 보고한다. 존재하지 않는 다운로드 URL을 만들지 않는다.

# Claude Code 클라우드 세션 실행 지시서 — 건축학 논문 중간발표 PDF 레퍼런스 기반 리디자인

## 0. 목표와 작업 성격

이 작업은 **건축학 논문 중간발표** 자료를 실사용 수준으로 개선하는 작업이다. 최종 논문 심사, 학회 발표, 기업 피치덱이 아니다. 현재 18장 PDF의 디자인만 조금 손보는 것이 아니라, 건축 및 학술 다이어그램의 **실제 시각적 레퍼런스를 연구한 뒤**, 각 슬라이드의 목적에 맞게 도식과 정보 구조를 개선하라. 기획서나 제작 가능성 검토로 끝내지 말고 실제 PDF를 완성하라.

사용 자료:
1. 현재 수정 대상: `vertical_flow_presentation_clear_titles.pdf` (18장)
2. 논문: `paper_revised_8pages_v2(2).pdf` (8쪽)
3. 필요 시 이전 PDF: `vertical_flow_final_modern_academic.pdf`, `vertical_flow_presentation_18pages_refined_typography.pdf`
4. GitHub: `edward321416-maker/vertical-flow-abm-midterm-talk`의 실험 코드와 결과 CSV
5. 사용자가 최종 확정한 발표 대본 (이전 대화에서 제공한 버전)

클라우드 세션에서는 로컬 ChatGPT의 `/mnt/data/` 경로를 자동으로 사용할 수 없다. **실제로 업로드되거나 클라우드 작업 디렉터리에 존재하는 자료만 열어라.** 파일이 없다면 저장소에서 확인 가능한 자료를 활용하고, 접근하지 못한 자료는 명시한다. 접근하지 않은 PDF를 분석했다고 주장하지 않는다.

## 1. 반드시 바로잡아야 할 현재 문제

### A. 중간발표에 어울리지 않는 표현
- 표지에 '대한건축학회 학술 발표'라는 표현이 남아 있다면 실제 목적에 맞게 **'논문 중간발표'**로 변경한다. 존재하지 않는 학회 발표·소속·행사명을 만들어 넣지 않는다.
- 슬라이드 전체의 어조는 '연구를 통해 모든 설계 문제를 해결했다'가 아니라, **'현재까지 수행한 모델 실험, 분석 결과, 해석 범위, 향후 검증'**이 되도록 한다.
- 결론을 없애지는 말 것. TOP1이 네 시나리오 중 최상단 유량에 가장 유리했다는 결과는 분명히 쓰되, 실제 건물의 보편적 최적안처럼 단정하지 않는다.

### B. 표지만 바꿨을 뿐 목차에 남은 내부 코드형 제목
- 현재 '발표 구성'의 항목 **'04 RQ1 · RQ2', '05 RQ3 · RQ4'**가 남아 있다. 이것은 수정 누락이다.
- 본문 슬라이드에서도 `RQ1`, `RQ2`, `E1`, `E2`, `γ`, `AUFR`가 **청중에게 설명 없이 제목 역할을 하고 있는지** 전체 텍스트를 검색해 점검하라.
- 내부 실험 식별자(RQ1~RQ4, E1/E2)는 수치 추적 및 학술적 정확성을 위해 **작은 보조 레이블이나 각주에는 유지**하되, 사람들이 처음 보는 제목·목차·결론에서는 **그 페이지가 다루는 현상이나 질문을 쉬운 한국어로 설명**하라.
- 화면에 보이지 않는 텍스트 객체·PDF 중복 레이어·본문 중간 제목·차트 주석까지 검사해, 수정 전 용어가 남아 있지 않도록 한다.

**발표 구성 슬라이드에서 사용할 권장 6항목(자료 흐름에 맞춰 조정 가능):**
1. 연구 배경과 핵심 질문
2. 선행연구와 분석 방법
3. 시뮬레이션 조건과 실험 설계
4. 층간 상행유량 감소와 프로그램 구성
5. 이동 저항과 앵커 배치에 따른 차이
6. 현재까지의 분석 결과와 향후 검증

특히 '04 RQ1 · RQ2'를 **'층간 상행유량 감소와 프로그램 구성'**, '05 RQ3 · RQ4'를 **'이동 저항과 앵커 배치에 따른 차이'**로 교체하라. 번호와 줄바꿈, 카드 폭 등 텍스트 배치도 함께 검사한다.

**제목 작성 규칙:**
- 장 제목은 가급적 25자 안팎의 자연스러운 한국어로, 슬라이드에서 답하는 질문 또는 확인된 현상을 표현한다.
- 제목만으로 연구적 주장이 과장되지 않도록 한다. 통계적으로 관측한 **연관성**을 직접적인 인과 효과나 실제 현장 검증으로 표현하지 않는다.
- 너무 긴 문장형 제목을 강제로 한 줄에 밀어 넣지 않는다. 짧고 의미 있는 제목 + 한 줄 부제로 나눈다.
- 감성적인 슬로건, 추상적인 단어 나열, 상투적인 AI 광고 문구는 쓰지 않는다.
- 예: 'RQ2 — 프로그램 대비와 AUFR' → **'인접층 프로그램 차이와 상행유량비'**, 부제에 '유인 계수별 통계적 관계' 표기.

## 2. 이번 작업의 중심: 실제 다이어그램 레퍼런스 조사

생성 전에 **관련 디자인 레퍼런스를 먼저 수집하고 분석하라.** 이미지 스타일만 흉내 내지 말고, 각 그림의 정보 조직 원리를 파악해 본 연구에 적용한다.

### 우선 참고할 신뢰할 만한 자료

- Datawrapper, dot plots: https://www.datawrapper.de/academy/how-to-create-a-dot-plot

추가 검색 주제:
- architectural program distribution matrix / circulation vs programmed space diagram
- non-spatial floor abstraction diagram architecture
- scientific multipanel figure minimal editorial research
- uncertainty forest plot, categorical coefficient plot
- architectural research presentation program zoning comparison

**필수 레퍼런스 수집 절차:**
1. 건축 다이어그램 4건 이상, 학술 그래픽·데이터 시각화 4건 이상을 찾는다. 가능하면 원 출처를 사용한다.
2. 각 레퍼런스에 대해 URL, 제작자/출처, 표현의 목적, 본 발표에 적용할 시각적 원리, 적용 금지 요소를 기록한다.
3. 실제로 열어 보았고 화면을 확인한 레퍼런스와, 검색 결과만 확인한 레퍼런스를 구분한다.
4. 레퍼런스에서 **선의 위계, 정렬, 공백, 직접 레이블, 비교축의 통일, 범례 최소화, 스케일** 같은 설계 원칙만 가져온다.
5. 타인의 다이어그램을 복사·트레이싱하거나, 권한 없이 그림을 재사용하지 말고 **우리 데이터로 새 SVG·벡터 다이어그램을 제작**한다.
6. 레퍼런스가 실제 건물 계단·에스컬레이터·평면을 그린 것이어도 우리 모형은 **실제 공간 형상을 재현하지 않은 합성 층 단위 모형**이므로 그런 물리적 형상을 함부로 차용하지 않는다.
7. 레퍼런스 조사 결과를 `references_review.md`로 내부 기록하고, 최종 제출 요약에 핵심 4~6개 출처 링크를 제공한다.

## 3. 전체 18장 시각화 구조 리디자인

**같은 9층 도식, 같은 카드, 같은 좌측 그래프+우측 숫자 레이아웃을 반복하지 말 것.** 그렇다고 슬라이드마다 새로운 장식 요소를 강제로 추가하지도 말 것.

### 페이지별 우선 설계
- **01 표지:** 단면·화살표를 제거한 타이포그래피 기반의 담백한 **논문 중간발표** 표지. 연구 제목과 발표자만 명료하게.
- **02 발표 구성:** RQ 번호만 적힌 항목을 위 '6항목'처럼 쉬운 한글 제목으로 교체. 장식 카드 6개를 기계적으로 나열하지 말고 **번호형 에디토리얼 목록 또는 2열 문서형 목차**를 검토.
- **03 연구 배경:** '왜 절대 유량뿐 아니라 비율을 봐야 하는가'를 보여주는 두 상황 비교 그래픽. 실제 연구 수치가 아닌 설명용 수치는 **가상 예시** 표시.
- **04 분석 단위:** 경계 유량 U, 인접 경계 비율 AUFR, 첫 경계 대비 최상단 상대 유량 T를 서로 다른 질문에 대응시키는 **수식 비교 레이아웃**. 기호 `b−1`, 그리스 문자·아래첨자 검증.
- **05 선행연구:** Chang & Penn(1998)의 실제 다층 복합공간 분석과 본 연구의 합성 층 선택 모형을 **서로 다른 분석 범위를 비교하는 대비도**로 표현. Barbican과 South Bank 모두 검토; 실제 관찰 연구의 결과를 우리 모형의 검증이라고 표현 금지.
- **06 연구 질문:** 전문용어 나열형 표를 짧은 질문 네 개의 구조로 변경. RQ1~RQ4는 작은 번호로만 보조 표시.
- **07 에이전트 모형:** 9층 전체 구조를 필요한 경우 **이 페이지에서만 한 차례** 사용. 같은 방향의 긴 화살표 한 개는 모든 사람이 1→9층 이동하는 것으로 오해를 유발할 수 있으므로, 8개 경계 측정 위치와 확률적 목적지·퇴장 선택을 분리 표현. 실제 평면·에스컬레이터를 그리지 말 것.
- **08 AUFR 정의:** 9층 전체 단면을 반복하지 말고 3개 층, 인접한 두 경계만 확대해 `AUFR₄=U₄/U₃`를 명확히 나타낸다. 바로 앞 수식 페이지와 중복되면 개념 설명을 통합하거나 분량을 재배치한다.
- **09 실험 설계:** 제목을 '이동 저항과 앵커 배치를 나누어 비교했다' 등 쉬운 말로 변경. **E1 = 저항×유인 계수의 요인 설계 매트릭스**, **E2 = 총량 고정·배치 변형**을 별도 시각 언어로 표현. E1 1600회/E2 1000회 합계 2600회 검증.
- **10~11 기본 유량과 AUFR:** 절대 통과 유량 라인 그래프와 국소 AUFR 그래프는 분리, 데이터 라벨·모집단·4일 합계를 정확히 표시.
- **12 인접층 프로그램과 AUFR:** +6.0%, +10.9%, +18.4%를 효과크기 비교와 **95% 신뢰구간**으로 보여 줄 방법을 검토. 별도 장식 숫자 패널보다 자료가 중심이 되게 한다. 퍼센트포인트 상승이라고 오기하지 않는다.
- **13 절대 유량 보조 분석:** 10.2/60.1/39.7%는 U의 기준모형 대비 잔여 데비언스 감소율. AUFR 결과와 다른 통계량임을 제목과 주석에서 명확히 구분.
- **14 동선 마찰의 조절 효과:** 점추정치와 95% CI를 가진 **포리스트 플롯**, 0 기준선과 신뢰구간 여부를 직접 표시. γ=4·8의 효과 없음으로 단정 금지.
- **15 앵커 배치:** TOP1/STEP3/UNIFORM/LOW3를 **단일 층별 비중 매트릭스**로 비교. 2~9F 합계 ≈1.60. 수평 막대 길이와 직접 레이블을 중심으로 구성. 네 개의 단면 반복 금지.
- **16 앵커 배치 결과:** 배치 → 경계별 RUI 궤적 → 최상단 상대 유량 T와 절대 U8 결과의 관계를 표현. 가능하면 4개 배치의 **층별 상대 유량 곡선**을 중심에 두고 최종 값을 작은 표로 연결. R은 정의 없이 숫자만 삽입하지 않는다.
- **17 연구 한계:** 실제 평면 미재현, 혼잡·용량 부재, 가정한 유인 계수 및 TOP1=0.85의 범위, 경계 통과량≠고유 방문객 등을 설명. 중간발표이므로 **'향후 검증 과제'**와 연계.
- **18 현재까지의 분석 결과와 향후 과제:** '종합 결론'이라는 단정적인 마감보다 **중간발표에 맞는 문구** 사용. TOP1의 조건부 우위는 명시하고, 실측 검증·기하학적 수직동선·혼잡 모델링을 후속 과제로 구분.

페이지 번호는 원칙적으로 기존 18장과 대응시킨다. 설명이 중복되면 통합할 수 있지만 논리와 결과를 희생하지 않는다. 슬라이드 수를 조정했다면 매핑표를 함께 제공한다.

## 4. 디자인 명세

- 16:9 가로. 모든 슬라이드 배경 `#FFFFFF`.
- 제목과 본문은 검정. 위계는 크기·굵기·불투명도(예: 100/75/55/30%)와 여백으로 표현.
- 색상은 **데이터 그래프 또는 연구 비교 시각자료에만** 최소한 사용; 표지·목차·강조 박스에 색 금지.
- 기존 사용자의 피드백대로 **제목을 지나치게 크게 만들지 않는다.** 일반 슬라이드 제목은 기존 22pt 전후를 기준으로 정교하게 조정, 표지는 기존 28pt 전후. 일부 페이지에서 공간이 남는다고 제목을 키우지 말 것.
- 한글과 숫자에 일관된 산세리프 1종을 우선 사용. 슬라이드 간 Pretendard와 NanumBarunGothic 혼재 해결. 글꼴 존재와 임베딩 확인.
- 그래프 축, 직접 레이블은 실제 발표 화면에서 읽히도록 하되 논문 지면용 5~7pt 지침을 그대로 16:9 발표자료에 적용하지 않는다.
- 도형의 선 굵기, 평행축, 텍스트 시작선, 여백 기준을 통일.
- 무의미한 화살표·범용 아이콘·컬러 카드·과도한 분절·그림자·장식적 슬로건 제거.
- 수식이 물결표·사각형·깨진 아래첨자·공백 누락으로 표시되면 재조판하고 재렌더링.
- 레이아웃 다양성은 **정보 유형의 차이에서만** 확보한다. 슬라이드마다 다른 스타일을 쓰라는 뜻은 아니다.

## 5. 학술 정확성의 잠금 조건

최종 결과를 아래 수치/정의와 대조한다. 논문·CSV와 불일치 시 정확한 출처를 확인하고 정정하며, 발표 대본을 근거 없이 다시 쓰지 말 것.

- 합성 9층, 8개 상행 경계. U₁=1F→2F 통과량, U₈=8F→9F 통과량. 건물 입장객 수가 아님.
- AUFR_{r,b}=U_{r,b}/U_{r,b−1}. 동일 반복의 경계 통과량 비율이며 개별 방문객 생존율이 아님.
- RQ1 γ=0 연속형 U1≈12,346, U8≈448, 마지막/첫 경계≈3.6%, 마지막 국소 AUFR≈51.7%, 분절형 첫 경계≈20.6% 낮음.
- RQ2 연속형 γ=2/4/8에서 Δx=0.1 증가 관련 AUFR 상대 승수: 약 +6.0/+10.9/+18.4%. 프로그램 반응을 외부 실측으로 검증한 효과가 아님.
- RQ2 U 보조 분석 γ=4 연속형 deviance 감소율 Δx≈10.2%, x_upper≈60.1%, M_above≈39.7%. 다른 통계량이므로 혼합 금지.
- RQ3 분절형 원척도 기울기 잠식률 γ=2: 6.7% (95% CI 2.7~10.5), γ=4: 0.8% (−4.1~5.2), γ=8: 1.7% (−6.4~8.6).
- RQ4 γ=4 연속형 TOP1 58.7%, STEP3 14.0%, UNIFORM 5.9%, LOW3 1.5%는 **반복별 U8/U1을 구한 뒤 평균한 값**. TOP1 U8 평균≈9,112명. 실제 방문객 도달 확률은 아님.
- 2~9층 앵커 비중 합계≈1.60. TOP1 9F=0.85·나머지≈0.107143, STEP3 3·6·9F=0.45·나머지=0.05, UNIFORM=0.20, LOW3 2·3·4F=0.45·나머지=0.05.
- γ는 실측 집객 계수가 아닌 가정한 민감도 값. 실제 두타몰 평면·도착률·개별 보행 궤적을 검증한 연구가 아님.

## 6. 작업 실행과 QA — 계획만 하지 말고 끝까지

1. 현재 PDF 18장과 논문을 확인하고 전 페이지 150~200dpi 이미지로 렌더링한다.
2. 각 페이지의 모든 제목·목차 항목·표 안 제목·범례·각주를 추출하고 `title_inventory.csv`로 만든다. 사용자에게 보인 'RQ1·RQ2' 잔존 오류를 반드시 찾아낸다.
3. 위 출처를 포함해 실제 다이어그램·차트 레퍼런스를 수집하고 `references_review.md`에 기록한다.
4. 18장 각각에 `current issue → source reference → design principle → new figure type → verified data`를 정한 뒤 구현한다.
5. 기존 PDF 위에 지우개처럼 검정 사각형을 덮고 텍스트만 바꾸는 방식을 지양한다. PDF 원본 프로젝트를 찾거나 벡터 기반 슬라이드를 재생성해 실제 내용 레이어를 교체한다.
6. 필요 시 PptxGenJS/SVG/Matplotlib/PDF 엔진을 사용하되 최종 결과는 **PDF만** 제출한다. 임시 소스와 이미지 폴더는 내부 보관.
7. 모든 슬라이드를 최종 PDF에서 이미지로 다시 렌더링한다. 전체 접촉 시트와 함께 **18장 개별 페이지**를 눈으로 확인하고, 제목 넘침·작은 글씨·수식 깨짐·색상 위반·반복 도식·자료 오기를 수정한다.
8. 통과 기준: ①목차 `RQ1·RQ2 / RQ3·RQ4` 잔존 0 ②표지 '논문 중간발표' 표현 ③9층 전체 모형도 최대 1개 ④AUFR 수식 오류 0 ⑤CSV 수치 일치 ⑥16:9 ⑦흰색 배경 및 검정 텍스트 ⑧최종 PDF 검색 가능 ⑨18장 전체 렌더 검증.
9. 레퍼런스 사이트나 Modal에 접근할 수 없다면 사실대로 기록하고 접근 가능한 고품질 소스/로컬 툴을 사용한다. **접근했다고 허위로 주장하지 않는다.**
10. GitHub 원본·논문 원고·기존 PDF를 덮어쓰지 않는다. 소스 코드 수정이 필요하면 별도 브랜치와 diff로 보존한다. 외부 결제, 모델 플랜 변경, 자격 증명 추출·노출, 새로운 광범위 권한 요청을 하지 않는다.

- 이 작업은 **Claude Code 클라우드 세션**에서 수행한다. 로컬 Claude Code/API 과금과 사용자가 보유한 클라우드 세션 크레딧을 혼동하지 않는다.
