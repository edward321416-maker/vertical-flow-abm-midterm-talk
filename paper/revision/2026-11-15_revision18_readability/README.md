## 수정 목표와 실제 적용
- '프로그램'과 식음 앵커 비중을 첫 등장 근처에서 정의했다. 앵커 비중은 가상 입력값이며 실측 면적 비율이 아니다.
- U(누적 경계통과량) → AUFR(바로 아래 경계 대비) → RUI(첫 상향 경계 대비)를 차례로 도입하고, 요약지표 T와 R은 연구방법에서 정의했다.
- RQ2는 AUFR 관련성(1.109배)과 U 잔여 편차 감소율(바로 위층 지표 60.1%)을 별개 질문으로 제시했다.
- RQ3는 '기본 경계 통과량이 줄었는가'와 '프로그램 유인에 대한 반응 민감도가 약해졌는가'를 분리해 설명했다.
- RQ4는 58.7%가 고유 방문객 도달 확률이 아니라 처음·마지막 경계의 누적 통과량 비율임을 명시했다.
- 논의에서 한계 및 후속 관측-보정-검증 문장의 반복을 통합하고, 결론은 질문→발견→한계 순으로 정리했다.

## 계측·형식 검수
- A4 2단 / 정확히 8쪽 / Figure 1~7 / Table 1~10 / 수식 2개
- 모든 figure와 caption은 같은 페이지이며, 텍스트 객체 페이지 밖 배치 0건
- 최종 XeLaTeX 컴파일 경고 0건, PDF 1.4 변환 전후 페이지별 추출 텍스트 동일
- RQ1~RQ4 주요 수치 및 18개 셀 2,600회 기록을 고정 실험 CSV와 재대조
- 이미지 원본 7개는 Revision17 사용본과 동일
- 이해도는 편집 검수로 평가했으며 실제 일반인 대상 독해실험은 시행하지 않았다
- 원본 휴먼명조·Times New Roman 미설치: Noto Serif CJK KR·Tinos 대체서체 적용
- 마지막 페이지의 남는 여백은 문장을 불필요하게 늘려 채우지 않았다
