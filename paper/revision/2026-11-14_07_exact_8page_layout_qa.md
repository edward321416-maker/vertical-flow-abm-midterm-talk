# 졸업논문 최종 개정본의 정확한 8쪽 조판 검증 (2026-11-14)

**사용자 필수 조건: 전체 문서 정확히 8쪽.** 이 조건을 충족한 PDF·DOCX를 2026-11-14 대화에서 파일로 전달했다.

## 최종 결과

- PDF 파일명: 봉성현_졸업논문_전면개정본_8쪽.pdf
- DOCX 파일명: 봉성현_졸업논문_전면개정본_8쪽.docx
- 실제 PDF 페이지 수: **8쪽** (PyMuPDF 및 Word→PDF LibreOffice 렌더 확인).
- 구성: 1쪽 제목·영문 Abstract·국문 초록 / 2쪽부터 1. 서론 / 8쪽 한계·결론·참고문헌 종료.
- 결과물 조판: A4 단일단. **학회 2단 레이아웃을 준수했다는 의미는 아님**.
- 이전 9쪽 개정본과 **99개 문단의 모든 글자 내용이 정확히 일치**하고, 표 3개 전체 셀의 글자 내용이 동일하다.
- 그림 6개, 표 3개, 참고문헌 9편을 삭제 없이 보존했다.
- 모든 실제 PDF 페이지의 글자가 페이지 경계 밖으로 나가지 않았고 각 페이지 텍스트가 누락되지 않았음을 검사했다.
- DOCX도 동일한 조판 설정이나 Microsoft Word 설치 폰트/버전에 따라 자동 페이지 나누기가 달라질 수 있으므로 **제출은 8쪽으로 확인한 PDF를 권장**한다.
- 실제 PDF/DOCX는 로컬 대화 첨부로 전달한 파일로서 **이 GitHub 저장소에 바이너리를 업로드했다고 주장하지 않는다**. GitHub에 저장된 전체 개정 원고는 [05](2026-11-14_05_revised_full_manuscript.md), 내용 수정 이력은 [06](2026-11-14_06_revision_changelog_and_qa.md).

## 정확히 어떻게 맞췄나

- 초록 다음의 '1. 서론' 시작에 명시적 페이지 나누기.
- 본문 폰트 원 크기를 유지하고 문단 간격을 완만히 축소(Body Text 앞/뒤 4pt), 줄간격은 1.25로 조정.
- 그림 폭·높이 각각 약 4% 축소하여 읽기 쉬운 원자료 기반 그래프는 모두 보존.
- 캡션 뒤 간격 5pt, 원본의 '표 3' 직전 불필요한 강제 페이지 나누기 제거.
- 본문 텍스트·수치·도표 캡션·참고문헌 실제 내용을 수정·누락하지 않고 조판만 최적화.

## 검증 원칙

- 변환 방식: DOCX를 LibreOffice 기반 렌더러로 PDF 생성, PyMuPDF로 페이지 카운트=8 및 8개 페이지의 텍스트 존재 검사.
- 각 페이지 PNG 렌더와 8쪽 접촉 시트로 페이지 경계·글자·표·도판 시각 검수.
- 수치 검증은 이전 개정 감사의 E1/A2/A2b/A3/E2 CSV와 동일; 이번 작업에서 GAML/R 재실행 안 함.
- 바이너리 압축 파일의 ZIP 무결성 검사 통과.
- 제출 권장 형식: **검증된 PDF**.
