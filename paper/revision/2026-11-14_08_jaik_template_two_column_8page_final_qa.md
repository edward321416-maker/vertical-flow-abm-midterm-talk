## 기계적·시각적 QA 증거

- 최종 PDF 실제 페이지 카운트: **8**, PyMuPDF로 재확인. 모든 페이지 A4(595.28 × 841.89 pt).
- 페이지별 텍스트 추출 길이: **3254, 1888, 1600, 2453, 1776, 1509, 2374, 2635**. 비어 있는 페이지 없음.
- DOCX의 OOXML `w:cols` 정의에서 1단과 2단 모두 확인; 실제 PDF 페이지 2–8은 2단.
- 첫 페이지 Abstract, Keywords, 서론이 같은 페이지에 있는지 확인.
- DOCX 내 원문 데이터 그래프 **6개**, 자료표 **3개**(첫 페이지 시각 레이아웃용 경계 없는 표 1개 별도), 참고문헌 9편.
- 그림 Figure 1–6, Table 1–3, 1~5장 절 제목, RQ1 12,346, RQ2 60.1%, RQ3 6.72%, RQ4 58.7%의 텍스트 존재 검수.
- 여덟 페이지의 단어 bounding box를 검사하여 페이지 모서리 **12pt 경계 밖 단어 0개**.
- 마지막 페이지 참고문헌은 이단 내 배치, 끝에 일부 여백 남는 것은 실제 내용의 길이에 따른 자연 여백으로 빈 페이지 삽입이 아님.
- Word DOCX는 MS Office/폰트 차이로 페이지가 달라질 수 있으므로 **정확히 8쪽 제출 조건을 보장하는 검증 대상은 PDF**.

## 데이터·학술 내용 관련 경계

이 판은 **형식 수정**이다. 앞서 검수된 비공간 가상 9층 모델, E1/E2 2,600 실행 데이터와 관련 통계는 동일하게 유지하였다. 현장 관측으로 오인하는 설명은 재도입하지 않았다. GAMA/R/CSV를 새로 실행한 것이 아니며, 지도교수 최종 승인이나 실제 대한건축학회 HWP 템플릿과의 완전한 XML/한글호환성 검증은 뜻하지 않는다.
