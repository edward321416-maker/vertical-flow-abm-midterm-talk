## 무엇을 수정했는가?
결론 뒤의 A–J 부록을 제거했다. A–E의 핵심 모형·실험·측정·검사 설명은 연구방법으로, G/H의 필요 비교는 결과 절로 옮겼다. F와 I의 상세 경계별 수치 및 파라미터는 별도 보충자료로 보존했다. 본문과 중복되는 J 종합 해석은 삭제했다.

**중요:** 본문은 학회 일반 허용 6–12쪽 범위이지만 이전 별도 작업목표인 **정확히 8쪽**은 충족하지 않는다. 문장을 반복하거나 행간을 늘려 분량을 인위적으로 채우지 않았다. 공식 HWP 지정 휴먼명조의 대체 서체를 사용했으며 실제 한/글과의 픽셀 동일성, 실측 보행자료 검증, 전체 시뮬레이션 독립 재실행은 미확인이다.

이 저장은 별도 감사 브랜치에서 이루어졌으며 `main`과 원래 개정원고를 변경하지 않는다.
