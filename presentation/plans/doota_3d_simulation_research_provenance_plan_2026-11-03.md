# 두타몰 실제 공간 모델 기반 3D 시뮬레이션 — 연구 출처 정합성 계획 (2026-11-03)

**상태:** SCOPE_PROPOSAL / NOT_IMPLEMENTED / 실제 3D 보행실험 미수행. 사용자는 AI 생성 쇼핑몰 이미지가 아닌, **실제 두타몰을 Blender 등에서 모델링하고 시뮬레이션 실험했다는 연구 과정**이 드러나는 시각자료를 원함. 이 주장은 구현·실험·검증이 끝나기 전까지 발표에서 사용하지 않는다.

## 확인된 현재 사실

- 공식 두타몰 층별 안내(2026-11-03 확인): **B2, B1, 1F, 2F, 3F, 4F, 5F**, 총 7개의 판매층. 공식 출처: https://www.doota-mall.com/store/floor.do .
- 현재 논문 연구의 E1/E2는 **S00~S08(지상 9개 층)** 가상 모형으로 수행되었으며, 두타몰의 영업시간/요일 시간대 프로필을 **시나리오 참고값**으로 사용한 GAMA **비공간적 층 단위 nested-logit** 실험. 실건물의 벽/평면·에스컬레이터 정확 좌표/3D 위치·개별 보행경로를 계산하지 않음.
- 공식 층별 안내만으로 프로그램 *종류*는 알 수 있으나 상세 치수, 매장 면적비, 실내 평면/동선 치수는 검증되지 않음. 따라서 형상·층별 배치의 정확성은 별도 건축 도면 또는 현장 실측 없이는 한정적.
- 직전 생성형 AI 시각화의 BIM 라벨, 3D 실험 수행 암시, 실시간 동시 에이전트 수, 평균 체류시간 38.4분은 **현재 데이터/실험 증거가 아님**. 발표 실험 증빙으로 재사용 금지.

## 실제로 할 수 있는 두 단계

**A. 기존 논문 결과를 보존하며 'Blender로 시각화'를 사실로 만드는 트랙 (권장, 현재 발표 준비)**

1. 실건물 참고 이미지·공식 7개 판매층의 **층별 프로그램**을 근거 자료로 수집, 도면에 없는 형상·에스컬레이터 위치 등은 **추정/개념 모델**로 표기.
2. Blender에서 **'두타몰 참고 3D 단순 매스 모델'**을 실제 생성한다. 외관/매장 밀도는 검증 수준에 맞게 단순화하고 모델 원본, 생성 스크립트, 화면 캡처를 보존한다.
3. GAMA의 E1/E2 9층 결과를 해석하는 별도의 **9층 가상 실험 모델**을 만든다. 기존 CSV의 8경계 U값을 정확히 대응시켜 3D 층 스택의 길이·점·레이어로 시각화한다. **7층 두타몰 건물에 9층 실험의 8개 경계 값을 실제 관측값인 것처럼 오버레이하지 않는다.**
4. PPT 자료로 두 장면을 연결한다: **두타몰 참고 모델 구축**(참조 자료→3D 매스) / **9층 가상 실험 분석**(GAMA 모형→경계별 결과), 모델/분석 라벨과 실제/가정의 출처 구분.
5. 합당한 발표 표현: "**두타몰의 층별 운영·프로그램 정보를 참고해 3D 참고 모델을 만들고, 별도로 구성한 9층 가상 공간에서 GAMA 에이전트 시뮬레이션을 수행했습니다.**" (Blender 모델을 실제 만든 후에만 '만들고' 사용). `3D 공간 자체에서 실험을 수행했다`는 주장은 금지.

**B. 실제 두타몰의 공간에서 3D 에이전트 시뮬레이션을 수행해 그 표현을 사실로 만드는 트랙 (연구 설계 변경 필요)**

1. 두타몰 실제 각 층의 **검증 가능한 도면**(B2~5F), 에스컬레이터/계단/엘리베이터 코어 위치, 층 높이/매장 프로그램 면적(또는 표기된 추정치), 진입구와 통행 가능 구역을 수집.
2. Blender에 실제 층수의 3D 평면/수직 코어를 구축한다. 정확한 도면이 없으면 '**실건물 참고의 개념적 형상**'으로 한계를 유지하고 '실제 형상 재현'이라고 단정하지 않는다.
3. 3D 보행/경로 모델이 필요하다면 GAMA 공간모형으로 경로/동선 네트워크를 구성하거나 별도의 spatial ABM 엔진을 사용한다. 기존 floor-level 효용선택 + 모드 결정은 보존할 수 있으나, **개별 위치·계단 환승·경계 통과·시간 이벤트**의 공간적 모델링 규칙을 새로 명세한다.
4. 시뮬레이션 조건, random seed, 경계별 truth logs, 출력 CSV, 2~3개 재현성 테스트, 시각화가 로그와 일치함을 검증한 기록을 남긴다. 정확한 보행 실험을 주장하려면 최소한 **입력 기하 → 움직임/통과 이벤트 → 분석 CSV → 재현 결과**의 추적성이 있어야 한다.
5. **기존 E1/E2 논문 수치(9층, 8경계)는 새 두타몰 7판매층 공간 실험 결과로 대체하거나 직접 비교할 수 없다**. 새 결과는 별도 예비 실험(탐색/사례 연구)으로 제출하고 표본과 모델 한계를 명시한다.
6. 이 트랙이 완료되고 로그/화면을 실제 확인한 경우에만 '**두타몰의 공간구조를 3D로 재구성하고, 그 공간에서 보행자 에이전트 실험을 수행했다**'라는 표현을 쓸 수 있다.

## 시각자료 규칙

- 실제 Blender 뷰포트의 **solid/wireframe** 장면(노이즈 없는 건축 모델) + 시뮬레이션 결과를 별도 창으로 표시. 존재하지 않는 모델링/작업 로그를 합성한 UI 금지.
- 보행자는 구현된 모델의 **실제 기록된 상태**에서만 위치와 이동을 표현. 로그가 층 단위라면 위치를 추정한 **개념화된 점 배열**로만 표현하고 실제 경로라고 부르지 않는다.
- 실제 실험 로그의 `cell_id`, `rep_id`, `gamma`, `circ`, `U_b` 등, 재검증 가능한 항목만 표시. 가짜 재생시간/방문객 총인원/동선 궤적/체류시간 수치 금지.
- 3D 화면 하단에는 "**Doota-referenced conceptual 3D model**" 또는 "**9-floor GAMA floor-level simulation visualization (not spatial tracking)**"처럼 어떤 화면인지 정확히 표시.
- 이미지나 영상 캡처만이 아니라 **Blender 파일, 실행 스크립트, 실제 CSV/실험 파라미터, 검증 스크린샷**을 함께 남겨 출처를 입증한다.

## 결정 게이트

- 사용자의 최근 요구를 문맥상 **'연구에 직접 연결되는 실제 3D 구현과 실험'**으로 이해한다. 하지만 **원논문의 연구방법과 결과를 변경하는 것**은 중요한 연구 설계 변경이므로, 트랙 B로 이행할 때에는 실제 도면 보유 여부와 기존 9층 연구를 별도 실험으로 유지할지 정해야 한다.
- Blender 명령은 현재 작업 컨테이너에서 확인되지 않았으며 `bpy`도 설치되지 않았다(2026-11-03 확인). `trimesh` 4.11.1로 Blender에서 불러올 수 있는 GLB/OBJ 가상 모델 생성은 가능하나 **Blender에서 실제로 편집·렌더링했다고 주장할 수 없다**.
