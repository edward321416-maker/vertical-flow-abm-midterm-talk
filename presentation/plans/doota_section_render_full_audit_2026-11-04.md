## 3. 연구/시뮬레이션 위조 위험 (중대)
- 이미지 UI에 `floors=7`, `boundaries=8`로 표시하지만 연속된 **7층 사이 경계는 6개**. 7개 판매층이면 B2→B1→1F→2F→3F→4F→5F의 6개 경계. 이미지 그래프 축은 `5F,4F,3F,2F,1F,B1,B2`로 **상층부터 하층 방향**인데 이를 `상행유량 감소` 선형 그래프로 설명하므로 방향·분모도 엉킴. 7개 층 이름에 8개 경계/7개 수치가 병존함.
- 기존 논문 E1/E2 모형은 `S00=1F`~`S08=9F`의 **합성 9층·8경계**이며 `gamma` 실험 수준 `{0,2,4,8}`. 이미지 `gamma=0.30`와 `cell_id=..._g0_cont`는 일치하지 않음.
- 이미지 `U_b` 숫자(15,420;12,036;8,645;6,124;4,312;2,996;1,678) 및 총 방문객 18,436, cycle 48,720은 **검증된 E1 결과 CSV가 아니며 실제 실행 로그에서 얻은 값이라는 증거가 없음**. 원 `analysis/outputs/aik/aik_a1_profile.csv`의 E1 gamma0 cont U1..U8은 12346.405,7372.995,4654.045,3068.07,2064.69,1378.955,866.925,447.76 (200반복 평균, 각 반복 4일 합산).
- 원 코드 `simulation/vertical_flow.gaml` `headless_run type: gui`에는 `output/display/monitor`가 없어 이미지 같은 3D 실내 공간 뷰·통계 출력이 자동 생성되는 구조가 아님. 실제 실험은 배치/headless 수행. **AI 생성 이미지를 실제 GAMA 스크린샷으로 발표하지 말 것**.
- 이미지의 사람 점은 실제 좌표로 기록된 에이전트가 아님. 기존 모델은 **비공간적 층 단위 nested logit**이며 실제 방문객의 이동 궤적이나 상점 내부 시뮬레이션이 아니다.

## 4. 표현 및 후속 제작 권장사항
- 이 그림은 학술 발표의 **검증된 실제 사례 건축 단면·모형 실행 증빙으로 사용하지 않는다**. 사용할 경우 반드시 '**두타몰 층별안내를 참고한 개념 시각화 / GAMA 실행 캡처가 아닌 재구성 이미지**'로 표기.
- 실제 두타몰에 가까운 단면을 만들려면 현행 층별안내(검증), 2019 이후 현장 사진 및 에스컬레이터 위치, 코어와 출입구 평면, 34F 업무동과 판매부 연결 관계가 필요. 채광/동선의 역사적 흔적을 현재 형태라고 단정하지 않음. 소유주/시설 관리사무소에 도면 요청하면 가장 정확.
- **발표가 현재 원논문 재현 설명이라면:** 먼저 실제 가상 9층 모델의 GAMA GUI `display`를 별도 개발/캡처하고 **가상 9층·8경계의 데이터만 정확히 표시**. 두타몰 7층 개념 단면을 9층 논문의 수치·조건과 합성해서 하나의 실험처럼 보여주면 안 됨.
- **두타몰 실물 사례 연구를 새로 하고 싶다면:** 실제 7층 공간 모형을 따로 구축하고 새 조건으로 재실험·재집계해야 함.
