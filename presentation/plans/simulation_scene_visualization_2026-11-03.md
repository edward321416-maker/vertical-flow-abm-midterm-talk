# 층 기반 GAMA 시뮬레이션 실행 장면 재구성 시각화 — 2026-11-03

**상태:** 이미지 시안 제작 완료 · 사용자 검토 대기 · 실제 GAMA 프로그램 화면 캡처 아님. PPT 본문/슬라이드 레이아웃 제작 작업은 하지 않음.

## 시각화 목적과 스타일
- 사용자가 원하는 것은 3D 상업시설 렌더 이미지, AI 마케팅 대시보드, 새 시뮬레이션 방법론이 아니라 **실제 논문이 수행한 층별 에이전트 시뮬레이션의 한 장면처럼 이해되는 도식**이다.
- 9층 합성 공간의 **얕은 축측 단면도**, 층별 에이전트 점, 경계별 상향 통과 카운터, **실제 CSV로 계산한 경계별 U_b 선 그래프**를 한 장면에 배치. 비현실적인 네온·화려한 조명·가짜 재생시간·실측 3D 경로를 배제.
- 편집 디자인: 백색/연회색, 청회색 한 가지 강조, 실제 데이터·모형 입력값만 작은 텍스트로 표시.
- PPT 제작은 사용자가 담당하므로 **완성된 PPT 전체 디자인 대신 PPT 삽입 가능한 시각자료 PNG/SVG**를 전달.

## 소스와 정확한 수치
- **원본:** `analysis/outputs/aik/aik_a1_profile.csv` SHA `8dbce330e593f62db7032b0bd91f94ba1b43773f`, cell_id `aik_e1_g0_cont`, 연속형, `gamma=0`, 200회 반복, 각 반복 4개 모의 일의 상향 통과 유량을 모두 합산한 값.
- **경계 b=1..8 순서의 `U_mean`:** 12346.405, 7372.995, 4654.045, 3068.070, 2064.690, 1378.955, 866.925, 447.760. PNG/SVG의 U_b 라벨을 정수 반올림해 표시하고 차트는 소수 원본값으로 제작.
- **T=U8/U1 지표:** 결과 CSV의 `RUI_mean(b=8)=0.0363039287507832`, 즉 **3.63%**. `U_mean(b=8)/U_mean(b=1)`은 엄밀히 동일 통계량이 아니므로 UI에서 지수 정의는 `U8/U1`로 표시하되 개별 반복 단위의 평균임을 설명.
- `gamma=0`은 **상층 프로그램 전부 제거**가 아니라 **추가 앵커 유인 항 비활성화**를 의미함.

## 표현과 연구적 한계
- **가상 9층**은 실제 두타몰 층수/형상을 복원한 모델이 아님. 연구 프로토콜 `docs/simulation/aik_experiment_plan.md` §1/§3: 비공간적 floor-level nested logit, 8 경계, GAMA 이동 이벤트 계산.
- 그림의 작은 에이전트 점은 **상대적 밀도의 개념적 기호**이며 실제 시뮬레이션의 개별 에이전트 위치 데이터로부터 재구성한 것이 아니다. 화살표 역시 특정 경로를 그린 것이 아니라 각 경계 상향 통과를 설명한다.
- 합계가 아닌 **4일 합산 유량의 200회 반복 평균**임을 하단에 표기. 단일 순간 스냅샷 값으로 오해하지 않게 한다.
- **실제 GAMA 캡처/BIM 3D 경로 시뮬레이션/실제 두타몰 실측 결과**로 표현하지 않는다.
- 사전에 생성한 AI 대시보드의 가짜 실행 시간·임의 에이전트 수·임의 경계 수치를 사용하지 않고, **CSV 기반 코드 렌더 SVG→PNG**를 PPT용 최종 시안으로 채택.

## 제작 파일 및 검증
- `simulation_scene_data_grounded.png`: **2400×1350** 16:9 전체 연구 화면, 한글/영문·층수·경계/데이터 확인.
- `simulation_scene_data_grounded.svg`: 같은 그림 벡터 원본.
- `simulation_model_only.png`: **1230×919** 층별 모델/경계 표시만 잘라낸 PNG. 사용자가 만드는 PPT 내 삽입용.
- 렌더: `make_scene.py`에서 SVG를 생성하고 CairoSVG로 PNG 변환, PIL로 PNG 치수 검증 및 중앙 모델 영역을 crop. 파일들은 **대화 아티팩트**에 존재하며 현재 GitHub에는 바이너리/SVG 파일이 업로드되었다고 주장하지 않는다. 이 마크다운은 출처·제작 조건·표현 한계를 기록하는 기획 이력.
- **다음:** 사용자가 원하는 '시뮬레이션 장면'의 구체성/톤 검토. 필요시 검증된 GAMA의 실제 단계·rep_id·crossing event 로그를 이용한 후속 제작으로 진행. 즉흥적 보행 위치 데이터 생성은 피한다.
