# 빌 힐리어(Bill Hillier)의 '자연 보행(Natural Movement)' 이론 기반 수직 보행 연구 프레임워크

작성일자: 2026-10-29  
연구 주제: 다층 상업시설의 공간구조와 수직 조닝이 층간 상행유량 감쇠에 미치는 영향에 관한 연구  

---

## 1. 단일 이론적 토대 채택 배경

다층 상업시설 연구에서 흔히 범하는 오류는 보행자의 이동을 상업적 매력도(MD, 마케팅, 테넌트 인지도)만으로 설명하려 하거나, 반대로 기계적인 수직동선(에스컬레이터 용량, 대기시간)만으로 환원하는 이분법적 접근입니다.

본 연구는 공간과 인간 행태의 관계를 과학적으로 정립한 **빌 힐리어(Bill Hillier)의 공간구문론(Space Syntax)과 '자연 보행 이론(Natural Movement Theory, 1993)'**을 단일 이론적 프레임워크로 채택합니다. 힐리어의 이론은 공간의 기하학적 형태(1차 원인)와 프로그램/토지이용(2차 승수)이 보행 유동과 맺는 엄밀한 인과적 위계를 제공합니다.

---

## 2. 빌 힐리어의 핵심 명제 및 개념

### 2.1. 자연 보행 (Natural Movement)의 정의
빌 힐리어는 1993년 기념비적 논문 *Natural movement: or, configuration and attraction in the urban grid*(Environment and Planning B)에서 다음과 같은 불변의 법칙을 선언했습니다:

> *"Movement is the functional product of the spatial configuration itself, prior to the distribution of specific land uses or attractors. Attractors do not generate movement from scratch; rather, the configuration generates a fundamental pattern of movement, and attractors act as multipliers upon this grid-driven flow."*  
> (보행 이동은 특정 토지이용이나 유인체가 배치되기 이전에, 공간 구조(배열) 자체의 기능적 산물이다. 유인체는 무에서 유량을 창출하지 못하며, 공간 구조가 생성한 근본적인 유량 패턴 위에 작용하는 '승수(Multiplier)'로서 기능한다.)

### 2.2. 인과적 3단계 위계 구조
힐리어의 공간-보행 이론은 다음의 3단계 위계로 설명됩니다:
1. **공간 구조 (Configuration):** 물리적 그리드, 시각적 통합도(Integration), 위상적 깊이(Depth).
2. **자연 보행 유량 (Natural Movement Flow):** 공간 구조에 의해 격자 전반에 자연스럽게 형성되는 1차 보행 밀도.
3. **유인체와 승수 효과 (Attractors & Multiplier Effect):** 소매점, 앵커 테넌트 등은 자연 보행이 높은 곳에 입지하여 시너지를 내거나, 특정 공간의 유량을 국지적으로 증폭시키는 2차적 변수로 작동.

## 3. 다층 상업시설(수직 공간)로의 이론적 확장

힐리어의 원래 이론이 도시의 2차원 수평 가로망(Street Grid)을 대상으로 했다면, 본 연구는 이를 **'다층 상업시설의 3차원 수직 단면(Vertical Section)'**으로 확장 적용합니다.

```
+---------------------------------------------------------------------------------+
|                                 [ 3차원 수직 공간 ]                             |
|                                                                                 |
| 1. 수직 공간구조 (Vertical Configuration) ➔ 1차 보행 생성자                      |
|    - 층간 수직 깊이 (Vertical Metric & Topological Depth)                       |
|    - 수직동선 기하학 (에스컬레이터 연속성: 직렬 vs 교차 vs 분산 우회)             |
|    - 아트륨 보이드(Void)에 의한 층간 시각적 가시성 (Visual Integration)         |
|                          │                                                      |
|                          ▼                                                      |
| 2. 기본 자연 감쇠 (Natural Vertical Attenuation)                                |
|    - 지상 진입층(1F)에서 상층부로 갈수록 위상적 깊이가 깊어지며                    |
|      기계적/신체적 마찰로 인해 보행 유량이 지수적으로 감쇠함                       |
|                          │                                                      |
|                          ▼ ◄─── 3. 프로그램 승수 (Program Multiplier)           |
|                          │         - 층별 MD 조닝 (Vertical Zoning)             |
|                          │         - 앵커 테넌트 (영화관, 대형 서점, F&B 집적)    |
|                          ▼                                                      |
| 4. 최종 층간 상행유량 (Inter-floor Upward Flow & AUFR)                           |
+---------------------------------------------------------------------------------+
```

### 3.1. 전제 1: 수직적 깊이(Vertical Depth)와 자연 감쇠(Natural Attenuation)
* 보행자가 1층에서 2층, 3층, 상층부로 올라갈수록 공간의 **위상적 단계 깊이(Step Depth)**는 단조 증가합니다.
* 수직동선이 직렬 연속형(Straight Continuous)일 때는 단계 깊이 증가가 완만하지만, 교차 회전형(Scissor)이거나 매장을 통과해 우회해야 하는 분산형(Detached Walk-around)일 경우 위상적 깊이와 인지적 마찰이 급격히 증가합니다.
* 따라서 **층간 상행유량의 감쇠(Attenuation)는 인간의 단순 변심이 아니라, 공간 구조의 위상적 깊이에 따른 '자연적 감쇠(Natural Attenuation)' 현상**입니다.

### 3.2. 전제 2: 층별 프로그램의 승수 작용 (Program as Multiplier)
* 층별 MD와 앵커 테넌트는 그 자체로 보행자를 공중으로 순간이동시킬 수 없습니다.
* 앵커 테넌트(영화관, F&B, 테라스 등)는 상위 층으로 향하는 에이전트의 이동 동기(Attraction Mass)를 증폭시켜, **1차 공간 구조가 유발하는 자연 감쇠 곡선의 기울기를 완만하게 꺾거나 역전(Shower Effect)**시키는 2차 승수로 작동합니다.

### 3.3. 전제 3: 상층부 공동화(Upper-floor Hollowing)의 건축적 정의
* 상층부 공동화는 **"수직 공간 구조의 높은 위상적 깊이(동선 단절)"**로 인해 자연 감쇠율이 극도로 높은 상태에서, 이를 상쇄할 **"프로그램 승수(앵커 매력도)가 임계치 미만"**일 때 발생하는 시스템적 건축 실패입니다.
* 따라서 해결책은 단순한 MD 교체나 동선 변경 단독이 아닌, **"동선 기하학 최적화(마찰 저감) × 수직 조닝 최적화(승수 극대화)"**의 결합에서 도출됩니다.

## 4. GAMA 에이전트 기반 모델(ABM) 수식화

힐리어의 이론을 본 시뮬레이션의 수학적 에이전트 효용 함수로 정식화합니다:

$$U_{ij} = \beta_0 + \underbrace{\Big( \alpha \cdot \ln(M_j) + \gamma \cdot \text{F\&B}_j \Big)}_{\text{2차 프로그램 승수 (Attractor Multiplier)}} - \underbrace{\Big( \beta_1 \cdot d_{ij} + \text{Imp}_{\text{mode}} - \theta \cdot V_{ij} \Big)}_{\text{1차 공간 구조 마찰 (Configuration Friction)}}$$

* $i, j$: 출발 층 및 목적 층
* $M_j$: 목적 층의 유효 상업 면적 (Mass)
* $\text{F\&B}_j$: 목적 층의 식음료 및 체험형 테넌트 점유율
* $d_{ij} = |j - i|$: 물리적 수직 층수 차이
* $\text{Imp}_{\text{mode}}$: 동선 유형별 마찰 계수 (연속형 < 교차형 < 우회형 < 계단)
* $V_{ij}$: 아트륨 보이드(Void)를 통한 층간 시각적 연결도(Visual Integration Index)
* $\alpha, \gamma, \beta_1, \theta$: 각 요인의 민감도 파라미터

에이전트의 층간 전이 확률(Choice Probability)은 다항 로짓(Multinomial Logit)으로 결정됩니다:

$$P(j \mid i) = \frac{\exp(U_{ij})}{\sum_{k} \exp(U_{ik})}$$

## 5. 결론 및 건축적 함의

본 연구는 빌 힐리어의 자연 보행 이론을 바탕으로:
1. 다층 상업시설의 **수직동선 기하학**이 기본 보행 유량을 어떻게 제약하는지 정량화하고,
2. **층별 프로그램 조닝(Vertical Zoning)**이 이 제약을 얼마나 극복할 수 있는지를 9개 건축 시나리오 시뮬레이션을 통해 실증함으로써,
3. 향후 다층 상업시설 설계 및 리모델링에 활용 가능한 **"건축계획적 수직 조닝 가이드라인"**을 제시합니다.
